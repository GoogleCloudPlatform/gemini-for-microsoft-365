# PPT-04: Document to Deck Transformation Specification

## 1. Overview
Allows users to upload or attach rich text documents (`.docx`, `.pdf`, `.txt`, markdown), extract key narratives and quantitative findings, and transform them into professionally designed PowerPoint presentations.

## 2. Capabilities
- **Doc-to-Deck Chip**: Dedicated action chip (`📄 Doc to Deck`) opens a file picker or uses document context.
- **Narrative Extraction**: Generates structured executive outlines with dedicated title, problem, solution, and metric slides.
- **Batch Slide Creation**: Inserts all generated slides into the active PowerPoint presentation.
